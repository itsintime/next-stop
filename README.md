# 下一站 · 实习 JD 对比助手

把实习岗位描述（JD）和简历逐项对照，找出有证据的经历、需要确认的条件，以及可以练习的岗位任务。

- 粘贴 JD，导入 TXT、DOCX 或有文字层的 PDF，也可以直接粘贴简历文字。
- 查看岗位原句与简历证据，在对应条目补充真实经历或到岗信息。
- 按 JD 任务推荐练习：SQL 题支持浏览器端判题；开放场景题提供评价要点。
- 在开发模式下，使用题库工作台批量导入、审核、试跑并导出扩展题库。

## 本地运行

使用 Node.js 22.12+（推荐 Node.js 24）和 npm：

```sh
npm ci
npm run dev
```

打开终端显示的地址。可以载入内置 JD，也可以使用 `mode/match-session/examples/` 里的虚构岗位和简历。

## 测试与构建

```sh
npm test
npm run build
```

生产构建输出到 `dist/`，可部署到静态网站托管平台。题库工作台只在开发模式中显示；审核后的扩展题库通过 `mode/practice-bank/data/approved-bank.json` 随构建发布。

项目使用 React、TypeScript 和 Vite。JD 匹配、简历解析和 SQL 判题在浏览器运行，无需独立后端。当前仅记录 JD 来源链接，不自动读取招聘网页。简历确认后的文字保存在当前浏览器标签页的会话存储中。
